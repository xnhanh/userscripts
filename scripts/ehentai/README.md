# E-Hentai Userscripts

Các Userscript được phát triển bởi XNhanhS nhằm cải thiện giao diện và trải nghiệm sử dụng E-Hentai.

## Danh sách Userscript

### Mobile View

**File:** `mobile-view.user.js`

Tùy chỉnh giao diện E-Hentai cho thiết bị di động, cải thiện bố cục, điều hướng và khả năng hiển thị nội dung.

[Cài đặt Mobile View](https://raw.githubusercontent.com/xnhanh/userscripts/main/scripts/ehentai/mobile-view.user.js)

### Animated Filter

**File:** `animated-filter.user.js`

Bổ sung khả năng lọc nội dung liên quan đến ảnh động trên E-Hentai.

[Cài đặt Animated Filter](https://raw.githubusercontent.com/xnhanh/userscripts/main/scripts/ehentai/animated-filter.user.js)

## Yêu cầu

- Trình duyệt hỗ trợ Userscript.
- [Tampermonkey](https://www.tampermonkey.net/) hoặc trình quản lý Userscript tương thích.

## Cài đặt

1. Cài đặt Tampermonkey.
2. Chọn Userscript cần sử dụng ở phía trên.
3. Xác nhận cài đặt trong Tampermonkey.
