# XNhanhS Userscripts

Bộ sưu tập Userscript do XNhanhS phát triển, tập trung vào việc cải thiện giao diện và trải nghiệm sử dụng các trang web.

## Giới thiệu

Dự án chủ yếu hướng đến việc hiện đại hóa giao diện website thông qua JavaScript và CSS, đồng thời cố gắng duy trì các chức năng gốc.

Các Userscript được phát triển để sử dụng với Tampermonkey.

## Cài đặt

1. Cài đặt [Tampermonkey](https://www.tampermonkey.net/).
2. Chọn Userscript muốn sử dụng trong repository.
3. Mở tệp `.user.js` và chọn `Raw`.
4. Xác nhận cài đặt trong Tampermonkey.

## Đóng góp

Mọi người có thể báo lỗi, đề xuất cải tiến hoặc gửi Pull Request.

Vui lòng mô tả rõ những thay đổi khi đóng góp mã nguồn.
